# Pramit-OptimizedTrafficCLIP

Implementation and reproduction of the OptimizedTrafficCLIP approach from Pramit's paper.

## Project

This repository extends the completed Base TrafficCLIP implementation with:

- Statistical traffic features
- Dynamic prompting
- Statistical projection
- Multimodal feature fusion
- Hyperparameter tuning
- ONNX profiling and benchmarking
